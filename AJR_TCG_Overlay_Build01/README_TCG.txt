AJR TCG OVERLAY — BUILD 01

This package is separate from AJR Sports Build 23. It runs on port 8766 so both can coexist.

START:
Double-click START AJR TCG.bat

CONTROL BOARD:
http://localhost:8766/control.html

OBS FULL TCG OVERLAY:
http://localhost:8766/index.html

OBS TCG RIPPING OVERLAY:
http://localhost:8766/rip.html

BOARDS:
Board 5 — Pokémon Type: Grass, Fire, Water, Lightning, Psychic, Fighting, Darkness, Metal, Dragon, Colorless, Items, Trainers.
Board 6 — Pokémon Chaser: 30 editable chaser spots.

THEMES:
Electric TCG / Cosmic TCG / Elemental TCG. Theme selection affects both Full and Ripping overlays.

SPORTS SAFETY:
AJR_Breaks_Overlay_Build23.zip is not modified by this package. This TCG build has its own server, state file, assets, HTML, CSS and JavaScript.
